# Assignment 5: Statistical Analysis

**Objective:** Perform exploratory data analysis to understand data distributions and basic statistics.

**Orange Workflow:**
1. **File Widget:** Load a dataset like `housing.tab`.
2. **Feature Statistics Widget:** Connect to view central tendencies (mean, median), dispersion, and missing value counts for all features.
3. **Distributions Widget:** Connect to plot histograms and probability density functions.
4. **Box Plot Widget:** Connect to analyze quartiles and identify statistical outliers visually across different categorical groupings.
